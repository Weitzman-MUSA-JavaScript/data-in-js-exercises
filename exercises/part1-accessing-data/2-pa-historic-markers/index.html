Enter CORS Proxy Key

For this exercise you'll use a service called CORS Proxy to avoid cross-origin resource sharing (CORS) issues. You will need to sign up for a free account on CORS Proxy to obtain an API key. You will also need to ensure that your CORS Proxy account is configured in Monitoring only mode:

  1. Sign up for a free account on CORS Proxy.
  2. On the dashboard, click the Add domain button.
  3. In the Origin enforcement section, switch the enforcement mode from Blocked to Monitoring.
